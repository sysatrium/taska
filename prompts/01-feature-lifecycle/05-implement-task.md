# Feature 4.1 — Implement Task

## Purpose

Implement exactly one task from `tasks.md`.

## Required context

- `AGENTS.md`
- feature `spec.md`
- feature `plan.md`
- exact task block from `tasks.md`

## Rules

- implement only the assigned task
- do not expand scope
- write tests with the change
- ask clarifying questions before coding if the spec is ambiguous
- report changed files and acceptance-criteria status

## Quality gate

Accept only if the task is complete, scoped, and verifiable.
