# Maintenance 5.2 — Update Constitution

## Purpose

Update project-wide operating rules when foundational assumptions change.

## Trigger examples

- stack change
- security model change
- delivery model change
- architecture style change

## Required work

- update constitution sections
- identify impacted templates and prompts
- identify impacted feature specs
- communicate migration steps

## Quality gate

Accept only if project-wide rule changes are explicit and traceable.
