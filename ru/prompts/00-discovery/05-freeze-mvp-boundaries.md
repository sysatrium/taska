# Prompt — Зафиксировать границы MVP

## Цель

Превратить discovery в явные границы MVP до создания feature spec.

## Сформировать

- MVP outcomes
- must-have capabilities
- список out of scope
- критичные edge cases
- decision log по открытым вопросам, которые всё ещё влияют на delivery
