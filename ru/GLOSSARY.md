# Глоссарий русской версии

## Назначение

Этот файл задаёт единый словарь для русскоязычного использования SDD-репозитория.

## Основные правила

- Описательные разделы и инструкции пишутся по-русски.
- Имена файлов, каталогов и технических артефактов сохраняются в исходном виде.
- Английские термины допускаются только в названиях файлов, каталогов, стандартов и общепринятых технических обозначениях.

## Рекомендуемые соответствия

- bootstrap -> инициализация
- operating model -> операционная модель
- quality gate -> критерии готовности
- feature lifecycle -> жизненный цикл фичи
- project overview -> проектный обзор
- open questions -> открытые вопросы
- scope -> скоуп
- out of scope -> вне скоупа
- verifier -> проверяющий агент
- rollout -> вывод в эксплуатацию
- rollback -> откат
- task decomposition -> декомпозиция задач
- acceptance criteria -> критерии приёмки
- verification criteria -> критерии проверки
- forbidden patterns -> запрещённые паттерны
- edge cases -> пограничные сценарии
- constraints -> ограничения
- assumptions -> допущения
