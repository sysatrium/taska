# Шаблон задач

## Правила декомпозиции

- Одна задача = одна атомарная единица работы.
- Типичный размер задачи = 1-4 часа.
- У каждой задачи должны быть критерии приёмки.
- У каждой задачи должен быть способ проверки.
- Зависимости должны быть явными.
- Задачи должны быть упорядочены так, чтобы реализатор мог брать их по одной без перепланирования фичи.
- Задачи не должны молча принимать неразрешённые продуктовые или архитектурные решения.
