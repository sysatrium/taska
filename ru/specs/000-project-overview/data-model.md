# Верхнеуровневая модель данных

## Назначение

Описать ключевые доменные сущности, связи, инварианты и жизненные состояния, которые определяют систему.

## 1. Ключевые сущности

Для каждой сущности зафиксируйте:

- назначение
- важные атрибуты
- владельца или source of truth
- состояния жизненного цикла
- чувствительные поля

## 2. Связи

Опишите, как сущности связаны друг с другом.

Для каждой связи зафиксируйте:

- тип связи
- кардинальность
- владение
- ожидания по консистентности

## 3. Инварианты

Задокументируйте доменные правила, которые должны оставаться истинными всегда.

- инварианты идентичности
- инварианты состояния
- финансовые или числовые инварианты
- временные инварианты

## 4. Переходы состояний

Опишите основные переходы жизненного цикла для важных сущностей.

Для каждой сущности укажите:

- начальное состояние
- допустимые переходы
- запрещённые переходы
- терминальные состояния

## 5. Чувствительные данные

Перечислите чувствительные, регулируемые или высокорисковые элементы данных.

- PII
- credentials или secrets
- финансовые данные
- поля, критичные для аудита

## 6. Открытые вопросы

Перечислите неразрешённые вопросы модели данных.
