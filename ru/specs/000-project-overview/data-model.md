# Обзор модели данных проекта

## Назначение

Описать доменную модель системы на уровне проекта до начала feature-level реализации.

## 1. Принципы моделирования

- Держать модель согласованной с утверждёнными границами проекта.
- Разделять подтверждённые сущности и inferred или provisional сущности.
- Не выдумывать детали хранения раньше времени.

## 2. Карта оснований

### Подтверждённые сущности

- Опишите подтверждённые доменные сущности.

### Выведенные сущности

- Опишите сущности, выведенные из утверждённого контекста.

### Временные сущности или связи

- Опишите временные modeling-defaults, требующие последующего подтверждения.

### Открытые вопросы

- Зафиксируйте неразрешённую неопределённость модели.

## 3. Ключевые сущности

Для каждой сущности зафиксируйте:

- имя
- назначение

- ограничения

## 4. Связи

- последствия удаления или изменения
